# Medication Side Effect Explorer

Explore side effects reported to the U.S. FDA (FAERS, via openFDA) for any medication:
top reactions, women vs men, trend over time and disproportionality signals (PRR).

Source code, notebook and methodology: https://github.com/sankara226/MEDICATION-SIDE-EFFECT-EXPLORER

**Educational use only, not medical advice.**
